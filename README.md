# AmazingCarbon Homebrew Tap

```sh
brew tap c4rb0nx1/tap https://github.com/AmazingCarbon/homebrew-tap
brew install memlane
brew install mog
```

| Formula | What it is |
|---|---|
| `memlane` | MCP memory server for AI agents |
| `mog` | Locks your Mac when someone else looks at it (Apple Silicon, macOS 14+) |
